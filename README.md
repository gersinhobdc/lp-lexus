# Lexus Automação Inteligente — Landing Page

Landing page de alta conversão desenvolvida por mim para a **Lexus Automação Inteligente**, empresa premium de automação residencial e corporativa em São Paulo (16+ anos de mercado, 2.500+ ambientes entregues).

🌐 **Site em produção:** [lexusbr.com](https://lexusbr.com)

---

## 🎯 Sobre o projeto

Página única (one-page) construída para captar leads qualificados de clientes interessados em automação de iluminação, som ambiente, climatização, segurança (CFTV) e rede Wi-Fi mesh. Toda a estrutura segue o funil **AIDA** — Atenção, Interesse, Desejo e Ação — com foco em conversão mobile-first.

### Destaques

- **Hero cinematográfico** com vídeo de fundo e copy focado em transformação
- **Formulário multi-step** (dois pontos da página) com captura via Resend + reCAPTCHA v3
- **Contador de escassez dinâmico** que decresce ao longo do mês e reseta automaticamente
- **Cards de serviços** com tilt 3D e imagens de fundo geradas por IA
- **Tema tech** azul-marinho com glow ambiente, grid de pontos e divisores estilo HUD
- **Smooth scroll** via Lenis, animações coreografadas com Framer Motion
- **Performance** otimizada — Lighthouse Mobile ≥ 85, LCP < 2.5s

---

## 🛠 Stack

| Camada | Tecnologia |
|---|---|
| Framework | Next.js 16 (App Router) + React 19 + TypeScript |
| Estilização | Tailwind CSS v4 |
| Animações | Framer Motion 12 + Lenis (smooth scroll) |
| Formulário | React Hook Form + Zod |
| Email | Resend |
| Anti-spam | Google reCAPTCHA v3 + Rate limiting (Upstash) |
| Deploy | Vercel |
